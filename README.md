# IntelliPDF 📄🤖

IntelliPDF is an AI-powered PDF Assistant that helps users upload PDF documents, generate AI summaries, create study notes, and ask questions based on the document using Google Gemini AI.

---

## ✨ Features

- 📄 Upload PDF documents
- 👀 View uploaded PDFs
- 📝 Generate AI summaries
- 📚 Generate study notes
- 💬 Ask questions about the PDF
- ⚡ FastAPI backend
- ⚛️ React + TypeScript frontend
- 🎨 Modern UI with Tailwind CSS

---

## 🚀 Installation

### Backend

```bash
cd backend

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

uvicorn app.main:app --reload
```

### Frontend

```bash
cd frontend

npm install

npm run dev
```
